# Begrepp och termer

### JavaScript (JS)

Ett programmeringsspråk som används för att skapa interaktiva och dynamiska webbsidor. JavaScript är till för att implementera funktionalitet på webbsidor, genom att exempelvis hantera knapptryck, rendera element och prata med API:er. Det är ett av de mest centrala verktygen för modern webbutveckling.

### HTML (Hypertext Markup Language)

Det grundläggande språket för att skapa struktur och innehåll på webbsidor.

### CSS (Cascading Style Sheets)

Ett språk som används för att designa och styla webbsidor. CSS kontrollerar layout, färger, typsnitt, spacing och alla visuella aspekter av en webbsida. CSS kombineras alltid med HTML, även om HTML kan fungera utan CSS.

### API (Application Programming Interface)

Ett gränssnitt som tillåter olika programvaror att kommunicera med varandra. I webbutveckling används API:er ofta för att hämta eller skicka data mellan frontend och backend.

### HTTP (Hypertext Transfer Protocol)

Protokollet som används för att överföra data på webben. Det är jämförbart med människospråk som svenska och engelska: även datorer måste ha språk för att förstå varandra, och HTTP är språket som används till webben. Man kan säga att saker tillhör "webben" om de använder HTTP.

### Fetch

En modern JavaScript-metod för att kommunicera med HTTP. Fetch används för att hämta data från API:er och uppdatera webbsidor dynamiskt utan att behöva ladda om hela sidan.

### Frontend

Den del av en webbapplikation som användaren interagerar med direkt i webbläsaren. Frontend omfattar allt som rör användargränssnittet och användarupplevelsen.

### Design

Den visuella och funktionella utformningen av en webbplats. Detta inkluderar färgval, typografi, layout och hur olika element fungerar ihop för att skapa en upplevelse.

### Structure (av webbsida)

Den logiska organiseringen av innehåll och kod i en webbapplikation. Bestäms ofta av HTML.

### Layout

Beskriver hur element på webbsidor är placerade. Att skapa layouts handlar om att bestämma ordning, riktning och struktur på element.

### Webb

En samling med datorer och nätverk av sammankopplade dokument och resurser som är tillgängliga via internet och HTTP protokollet. Webben är den plattform där webbsidor och webbapplikationer existerar.

### Webbsida

En enskild HTML-sida som kan visas i en webbläsare. En webbsida kan innehålla text, bilder, video och interaktiva element.

Denna term blandas ofta med hemsida och webbplats.

### Webbplats

En samling sammankopplade webbsidor som delar samma domännamn och tillsammans utgör en helhet. En webbplats kan vara allt från en enkel presentation till en komplex webbapplikation.

Exempel:

- Youtube
- Facebook
- Aftonbladet

Denna term blandas ofta med webbsida och hemsida.

### Hemsida

Huvudsidan (webbsida) för en webbplats. Hemsidan är ofta den första sidan besökare möter och fungerar som en utgångspunkt för navigation till övriga delar av webbplatsen.

Denna term blandas ofta med webbsida och webbplats.
