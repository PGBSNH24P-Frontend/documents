# Introduktion till frontend

Frontend handlar om all programmering som relaterar till mjukvara som interagerar med människor. Man kan säga att allt du "ser" är frontend. Teams, discord, din webbläsare och webbsidor, spel och mer, är alla exempel på frontend program. Du kan interagera med dem och de har ett gränssnitt, och därför ligger dem inom "frontend" kategorin. Typiskt sätt refererar frontend till webbsidor, och när man säger att man är en frontendutvecklare så menar man att man utvecklar webbsidor, men tekniskt sätt så är frontend större än så. I denna kurs kommer fokuset ligga på utveckling för webben.

Backend handlar om all programmering som relaterar till mjukvara som gör saker i bakgrunden, som inte interagerar med människor direkt. Däremot så kopplar ofta en frontend applikation till en backend applikation:

```
Backend app <-> Frontend app <-> Människor
```

Typiskt sätt så har alla frontend applikationer också en backend del, men den syns inte, och därför kallas det "backend". För att ta ett exempel från vardagen så kan du jämföra frontend-backend med en bil. Frontenden på bilen är ratten, pedalerna, alla knappar, stolarna och så vidare. Backenden på bilen är motorn, tanken och kanske hjulen. Det är oftast backenden som får hela systemet att fungera, men det är frontenden du interagerar med för styra systemet.

## HTML, CSS och JavaScript

HTML, CSS och JavaScript är byggstenarna för att utveckla webbsidor. De är några av de mest använda programmeringsspråken, om inte de absolut mest använda språken idag.

HTML och CSS används för att strukturera och designa frontend webbsidor, och de är till för att människor ska interagera med dem. Med HTML och CSS kan du skapa nästan vad som helst, speciellt när du kombinerar dem med JavaScript, som exempelvis: väderappar, produktsidor/ecommerce, spel, nyhetssidor och kalendersidor. Att utveckla med HTML & CSS handlar i stora drag om att skapa komponenter (knappar, titlar, paragrafer m.m) som placeras ut på specifika platser, eller med specifika layouts.

JavaScript används för att lägga till funktionalitet på webbsidor, så att något händer när du trycker på en knapp exempelvis. Utan JavaScript fungerar inte knappar, formulär, menyer och så vidare.

## Svårighetsgrad

HTML och CSS anses vara enkla att lära sig. Däremot innehåller de extremt många nyckelord (taggar, egenskaper) och därför kan det ta lång tid att bemästra dem.

JavaScript är likt andra programmeringsspråk och anses vara svårt att lära sig. Om man har kunskaper inom programmering från tidigare hjälper det väldigt mycket då de flesta koncept kan överföras mellan språk.
